HIIT Watch App
A lightweight, native Wear OS interval training application built specifically for smartwatches (such as the Samsung Galaxy Watch series) using Jetpack Compose and Kotlin.

Designed for fitness enthusiasts who want a distraction-free, high-intensity interval training (HIIT) timer directly on their wrist.

✨ Features
Customizable Intervals: Easily configure work time, rest time, and total rounds right from your watch.

Haptic Feedback & Visual Cues: Built-in vibration alerts for countdowns and phase changes, paired with color-coded screens (Work vs. Rest).

Wear OS Tile Support: Includes an official TileService integration so you can add the HIIT timer as a quick-access card on your watch's main carousel.

100% Native Performance: Lightweight design optimized specifically for watch batteries and circular displays, avoiding heavy web-rendering dependencies.

🚀 Getting Started
Clone this repository to your local machine.

Open the project in Android Studio (Koala or newer recommended).

Connect your Wear OS smartwatch via Wi-Fi or Bluetooth debugging (ensure developer options and adb debugging are enabled).

Click Run ▶ to deploy the app directly to your watch.

🛠 Tech Stack
Language: Kotlin

UI Framework: Jetpack Compose for Wear OS / Protolayouts

Architecture: Native Android Services & Coroutines
